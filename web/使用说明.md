# 汕大充电 · Web 验证版

设备目录已按《学校充电桩设备地址.docx》重写，与 Android 2.0.4 一致：14 台设备、280 个插座、8 处充电地点。

## 启动

双击“启动Web验证版.cmd”，或在本目录运行 `python server.py --port 8766`。需要 Python 3.10 及以上，无第三方依赖。本机预览：`http://127.0.0.1:8766/`。手机与电脑连接同一可互访网络后，可使用终端显示的局域网地址；电脑需保持运行并联网。

## 功能与状态

支持拖动、双指缩放、按标点选地点、按名称或编号搜索、地点和空位筛选、20 个插座详情、收藏及备注。手机总览以编号显示，编号与下方地点列表对应，放大后显示名称。

前台每 60 秒更新；每台至少间隔 60 秒，最多并发两台。超过 120 秒未成功更新、查询失败或状态未知的设备不计入当前空闲汇总。失败保留已有记录并显示日期与原因。

查询方式和 13 台历史状态来自用户指定的 [stu-charger](https://github.com/aiuanrou-hub/stu-charger)；设备名称与归属以用户文档为准。历史快照时间为北京时间 2026-09-07 00:37，只作历史查看；教师宿舍无预置历史状态。校园原图参考 Zagniki_ / 高德。

## 文件

- `data/device-locations.json`：文档导入表、照片对应与来源摘要。
- `data/catalog.json`：Web 与安卓共享目录。
- `data/repository-snapshot.json`：保留原始时间的历史状态。
- `assets/campus-map.json`：离线矢量地图。
- `设备地址对照表.md`：全部名称、编号与分组。
- `验证记录.json`：网页与数据检查记录。

验证使用桌面 Edge 的桌面和手机尺寸模拟；实体安卓浏览器运行仍待设备验证。

剩余空位颜色：红色为 0；黄色为有空位且占总插座不超过 25%；绿色为超过 25%。地图标点、地点编号、详情和设备卡片统一使用此规则；某地点有未成功更新的设备时，地点显示灰色。20 口设备对应 0 口红、1–5 口黄、6–20 口绿。
